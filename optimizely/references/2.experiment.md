# [Steps to create an experiment](https://docs.optimizely.com/web-experimentation/docs/steps-to-create-an-experiment#create-an-experiment)
Use the experimentation editor to:
- design variations
- define where the experiment runs and who sees it
- create events to measure success
- test and publish experiment

## Create an experiment
- name and description
- Set where your experiment runs
  - **Target By URL** to run an experiment once
  - **Target By Saved Pages** to run experiments on a set of URLs regularly
  - **[Page triggers and conditions](https://docs.optimizely.com/web-experimentation/docs/yrL4-dynamic-websites-and-single-page-applications)** to tell when to activate a page .

## Set your target
Choose how to target when creating the experiment for your targeting for the activation
  - triggers
  - conditions
  - test URLs
  - [audience](https://docs.optimizely.com/web-experimentation/docs/LlGT-target-audiences-using-the-audience-builder)

## Design your experiment
### Variations
- Change the layout, including the element's visibility or position. Rearrange the elements on the page.
- Modify or replace typography, images, background styles, or borders
- Add inline CSS.
- Fine-tune jQuery selectors
- Change the timing of the change from synchronous to asynchronous

### Shared Code
- apply code that is shared among all variations in the experiment
